# Code of conduct

Ariadne follows the
[**Contributor Covenant v2.1**](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in spirit and in letter. The canonical text lives at that URL; this
file pins the version we adopted and names the contact path.

In short:

- Treat people with respect — in issues, PRs, commit messages, code
  comments, and discussion threads.
- Disagreement is welcome; personal attacks, harassment, and
  intimidation are not.
- Assume good faith. Most "bad" PRs are someone trying to help with
  incomplete context.

## Reporting

Code-of-conduct concerns go to <kwanho0096@gmail.com>. Reports are
read promptly and handled confidentially. The maintainer (kwanhokim)
is currently the sole enforcement point — if a future report involves
the maintainer, escalate to a public discussion or fork.

Security vulnerabilities follow a separate path — see
[`SECURITY.md`](SECURITY.md).
