# Decisions log

An **example project** on the Ariadne platform. Product decisions as a
workspace: PRDs + ADRs + open questions in one folder, a weekly-digest
schedule, and an agent-staged ADR action.

- `template.ts` — seed docs, custom screen, `ACTIONS_YAML`.
- `server.ts` — create-flow starter (category `decisions`).
- `web.ts` — the New Workspace dialog card.
