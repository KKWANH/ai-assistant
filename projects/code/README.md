# Code project

An **example project** on the Ariadne platform. A tiny TypeScript repo as a
workspace, plus an edit-file action that demonstrates the safe staged-diff
flow (propose → review → apply).

- `template.ts` — seed files (src/, package.json), custom screen, `ACTIONS_YAML`.
- `server.ts` — create-flow starter (category `code`).
- `web.ts` — the New Workspace dialog card.
