# Chefbook

An **example project** on the Ariadne platform. A kitchen as a workspace:
`ingredients.csv` (with expiry), `tools.csv`, and a calorie-tagged
`recipes.csv`, surfaced as a pantry + recipe dashboard.

- `template.ts` — seed files + custom screen source.
- `server.ts` — create-flow starter (category `cooking`).
- `web.ts` — the New Workspace dialog card.
