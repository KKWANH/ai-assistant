# Reading library

An **example project** on the Ariadne platform. A reading list as a workspace:
`library.csv` of books/articles + a custom screen with status, ratings, and a
reading-pace chart.

- `template.ts` — seed file + custom screen source.
- `server.ts` — create-flow starter (category `research`).
- `web.ts` — the New Workspace dialog card.
