# Research papers

An **example project** on the Ariadne platform. A paper library as a
workspace: per-paper notes + a `.bib` + a reading queue, with a custom screen
that counts inbound citations and audits dangling ones.

- `template.ts` — seed notes/bib, custom screen, `ACTIONS_YAML`.
- `server.ts` — create-flow starter (category `research`).
- `web.ts` — the New Workspace dialog card.
