# Investment Advisor Workbench

This template demonstrates a custom AIWS app, not a quick action.

It combines:

- portfolio CSV holdings
- target allocation policy
- an interest/watchlist file
- optional network-approved quote snapshots
- deterministic rebalance math
- Markdown research report artifacts

It is educational scaffolding only and must not be treated as financial advice.

## How To Customize

1. Replace `files/portfolio.example.csv` with your holdings CSV.
2. Adjust `files/target_allocation.example.yaml`.
3. Put ETFs, stocks, or themes in `files/watchlist.example.csv`.
4. Run `market_research` only when you approve network access.
5. Run `rebalance_plan`, then `advisor_report`.
