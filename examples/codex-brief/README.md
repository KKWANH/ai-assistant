# Codex Brief Example

This example shows how AIWS can turn a project goal into a Codex-ready implementation brief.

## Try It

Open AIWS Home Workbench and choose **Create Codex brief**. Paste a short implementation goal such as:

```text
Add a safe file import command that validates paths under the workspace root.
```

Expected output:

- `codex-prompt.md`
- A run record describing inputs and generated artifact.
